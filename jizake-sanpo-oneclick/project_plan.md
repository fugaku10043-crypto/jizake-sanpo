# 地酒さんぽ

## 1. Project Description
日本酒初心者(20代中心)が、地図を触りながら気軽に「その土地らしい一杯」と地域の食・文化・旅の魅力に出会えるポップなWebサイト。日本酒を評価・採点する専門サイトではなく、地酒を入口に地域を楽しむための入門サイト。

## 2. Page Structure
- `/` - トップページ(地図+地域カード+初心者ガイド+このサイトについて)

## 3. Core Features
- [x] ヘッダー(ロゴ、ナビゲーション)
- [x] ファーストビュー(キャッチコピー+日本地図イラスト)
- [x] クリッカブルな8地域ブロック地図
- [x] 地域選択時の詳細パネル(おすすめ酒・味タグ・合わせる食べ物・土地の魅力・旅のひとこと)
- [x] 主要5県の地域カード一覧(新潟・石川・広島・秋田・福島)
- [x] 初心者向けガイド(5つの選び方)
- [x] このサイトについて
- [x] 飲酒に関する注意書き(20歳未満禁止・適正飲酒・飲酒運転防止)

## 4. Data Model Design
- 静的データ(mocks)で管理
  - regions: 8地域ブロック情報
  - prefectures: 5県の詳細情報
  - tasteGuide: 初心者向け選び方ガイド
