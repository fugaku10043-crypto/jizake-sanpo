# 地酒さんぽ：トップページのワンクリック集計 設定手順

## Google側（利用者が作業するところ）
1. [Googleスプレッドシート](https://sheets.google.com/) で新しいファイルを作り「地酒さんぽ・興味度集計」と命名。
2. 上部「拡張機能」→「Apps Script」を開く。
3. `GOOGLE_APPS_SCRIPT.gs` の内容を全部コピーして `コード.gs` に貼り付け、保存する。
4. 右上「デプロイ」→「新しいデプロイ」→ 種類を「ウェブアプリ」にする。
5. 「次のユーザーとして実行」は「自分」、「アクセスできるユーザー」は「全員」に設定し、デプロイする。アクセスが全員に公開される点に注意。
6. 求められたGoogle認証を完了して、末尾 `/exec` のウェブアプリURLをコピーする。

## サイト側
7. Vercelの該当プロジェクト → Settings → Environment Variables に `VITE_ONECLICK_ENDPOINT` を追加し、値に `/exec` URLを貼り付ける。Productionを対象にする。
8. この更新版コードをGitHubにアップロード・コミットし、Vercelで再デプロイする。環境変数を後から設定した場合も再デプロイが必要。
9. 公開サイトで選択肢を1回押す。Googleスプレッドシートの `興味度回答` シートに日時と回答が1行追加されることを確認する。

## 注意事項
- Googleフォームの6問は従来どおり、診断結果とページ下部のリンクから回答できる。トップの1問は**別のスプレッドシート**に保存される。
- フロント側は `no-cors` 送信のため、画面では実際のシート保存結果を検証できない。「送信しました」の後、必ず最初にシートに行が追加されたことを確認する。
- URLを知る人は誰でも送信可能。認証・レート制限なしなので、いたずらや重複を完全には防げない。アクセスが増えたら専用API/サーバーレス関数などを検討。
- Googleフォームで取得する興味度とトップの興味度は同じ人の回答かどうか結びつけていない。
- デプロイ先のURLはサイト内に含まれる公開情報となる。秘密情報を置かないこと。
